## Article format

Start with a precise question and enough game context to reproduce the situation. Explain each decision in order, cite the rules supporting it, and identify relevant card text and errata. Keep unresolved questions explicitly unresolved.

The mechanics index and individual card cases will be selected with the user before drafting; this outline does not claim to list every mechanic.

## Rules references

Start with [Riot’s current Core Rules, patch notes, and errata](https://playriftbound.com/en-us/rules-hub/). Use the [sources guide](/sources) to record the exact document, rule number or section, version, and review date for each future explanation.
