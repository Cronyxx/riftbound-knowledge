## Citing this edition

Use a rule’s number as its link text: [359.3.e.5](/reference/core-rules#rule-359-3-e-5). Replace periods with hyphens in the fragment: `/reference/core-rules#rule-359-3-e-5`. For a range, link both endpoints. Record the document version and your own review date beside the citation.

This is a supporting reference, alongside [Official sources](/sources). For explanations, follow [Basics](/basics/) or [Advanced Rules](/advanced/). Riftbound and the official document belong to Riot Games; this independent site does not issue official rulings.
