# Timing & chains

::: info Awaiting notes
This page collects questions to research. It does not yet describe verified timing procedures.
:::

## Questions to document

- When can a player play a card or activate an ability?
- When does a player get an opportunity to respond?
- How are objects added to a chain, and in what order do they resolve?
- What happens when an effect triggers during another effect’s resolution?
- At what point are costs paid and choices made?
- What happens if the situation changes before an effect resolves?

## How to explain a sequence

Start with the exact cards and game state. Write each action in order, identify which player makes each decision, and cite the rule that permits the next step. Include an example only after checking it against the source.

Find the current Core Rules through the [official sources guide](../sources.md), then use the [note template](../contributing.md).
