# Deckbuilding

::: info Awaiting notes
This page is a research checklist. Deck construction requirements have not yet been transcribed or verified here.
:::

## Questions to document

- Which format is the deck intended for?
- What are the required deck sizes and card copy limits?
- How do the legend, chosen champion, and domain identity constrain the deck?
- What are the rune deck and battlefield requirements?
- Does the format use a sideboard, and what restrictions apply?
- Do any current bans, errata, or event requirements affect the list?

## Where to check

Use the Core Rules for deck construction and the format’s legality section in the [official Rules Hub](https://playriftbound.com/en-us/rules-hub/). For an event, also check the Tournament Rules.
