# Card interactions

This is a supporting research checklist. See the [Advanced Rules learning path](/advanced/) for the published draft batch.

The [Special card interactions draft](/advanced/special-card-interactions) explains official FAQ cases involving Gravity Field, Charm, Angler Wyrm, and Runeblade Anvil. These explanations await user review.

## Record a situation

A useful interaction note starts with a precise question:

1. Name the cards using their full names.
2. Describe the format, locations, game state, and whose turn it is.
3. List the actions in order.
4. State the exact point of uncertainty.
5. Check current card text, errata, and the relevant rules.

## Add an interaction

After topic approval, create a Markdown file in `docs/advanced/` using the template in [Writing a rules note](../contributing.md). Add a link to the Advanced Rules index and sidebar configuration.

Keep unanswered situations marked **Open question**. Once an explanation has been checked, include its source and review date, then await user review before marking it **Sourced note**.
