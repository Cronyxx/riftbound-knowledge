# Official sources

Start at Riot’s [Riftbound Rules Hub](https://playriftbound.com/en-us/rules-hub/). It brings together the rulebooks, legality information, patch notes, and errata.

**Source links reviewed:** October 31, 2026. This notebook does not automatically synchronize with Riot’s documents.

## Pick the right reference

| Your question | Reference in the Rules Hub |
| --- | --- |
| How does a game procedure or effect work? | Core Rules |
| How is an organized event run or an issue handled? | Tournament Rules |
| Is a card or battlefield legal in a format? | Constructed Format Legality or 2v2 Constructed Legality |
| Has printed card text changed? | The relevant set’s Errata |
| Is there an explanation of an update or interaction? | Patch Notes |

Linking to the hub keeps the current documents easy to find without relying on an old PDF URL.

## Cite a rule in this notebook

Record these details with every explanation:

- The official source URL and document title.
- The document version or publication date.
- The rule number or section heading.
- The date you checked it.
- Any relevant card errata and the format being discussed.
