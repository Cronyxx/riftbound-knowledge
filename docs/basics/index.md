# Basics

Learn the goal, recognize the pieces, then follow a game from setup to scoring. Start with a prepared deck; learn to build your own after playing through an example.

::: tip First two lessons approved
[Objective of the game](/basics/objective) is approved as a sourced note. [Meet the cards](/basics/meet-the-cards) is approved as a sourced note. Later lessons await approval before drafting.
:::

## Lesson format

Each lesson teaches a simple concept using accurate game terms. Define each new term at first mention, and build on ideas already introduced. Include enough context and a useful gameplay example to explain how the concept works. Keep exact official references in an expandable source note so they remain easy to check. Technical procedures and exceptions belong in [Advanced Rules](/advanced/).
