# Basics

Learn the goal and the cards, then follow a game from setup to scoring. Start with a prepared deck and build your own after playing through an example.

::: tip All 14 Basics lessons approved
Each lesson includes an expandable note with official rule references.
:::

Start with the [Objective of the game](/basics/objective), or use [Your first game](/basics/first-game) to follow a practice Duel from setup to the winning point.

## Lesson format

Each lesson teaches a simple concept using accurate game terms. Define each new term at first mention, and build on ideas already introduced. Include enough context and a useful gameplay example to explain how the concept works. Keep exact official references in an expandable source note so they remain easy to check. Technical procedures and exceptions belong in [Advanced Rules](/advanced/).

## Rules references

Use the current [Core Rules via Riot’s Rules Hub](https://playriftbound.com/en-us/rules-hub/), alongside applicable patch notes and errata.
